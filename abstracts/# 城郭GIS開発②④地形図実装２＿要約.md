# 城郭GIS開発④「地形図実装２」引き継ぎ要約

## ① このチャットの目的

「城郭GIS開発②地形図実装」で確立したCS立体図作成手順を引き継ぎ、当初は以下を目的として開始した。

- 和歌山県3次元点群データからのCS立体図作成を半自動化する。
- 3×3＝9区画単位で処理し、和歌山県全域を速やかにCS立体図でカバーする。
- 個々の欠損や境界問題の完全解決より、まず全県展開を優先する。

その後、shi-works氏が和歌山県全域の1m CS立体図をすでに公開していることが判明したため、目的を変更。

最終的には、

> **shi-works版CS立体図を城郭GISへ接続して自作版と比較し、全県CSとして実用可能か検証する**

ことが、このチャットの中心課題となった。


## ② 実装・変更した内容

### A. shi-works版CS立体図を試験導入

shi-works氏が公開している和歌山県CS立体図XYZタイルを `main.js` に追加した。

使用しているタイルURL：

```text
https://xs489works.xsrv.jp/raster-tiles/pref-wakayama/wakayamapc-cs-tiles/{z}/{x}/{y}.png
```

Leafletでの設定：

```javascript
const shiworksCsMap = L.tileLayer(
    "https://xs489works.xsrv.jp/raster-tiles/pref-wakayama/wakayamapc-cs-tiles/{z}/{x}/{y}.png",
    {
        minZoom: 4,
        maxZoom: 18,
        maxNativeZoom: 17,
        opacity: 1.0
    }
);
```

shi-works版はネイティブではZL17までだが、

```javascript
maxZoom: 18,
maxNativeZoom: 17
```

とすることで、ZL18ではZL17タイルをLeaflet側で拡大表示する。


### B. 自作CSとの比較

一時的に以下の3レイヤーを切替可能にした。

- 自作CS立体図
- shi-works 和歌山県CS立体図
- 城館等

複数地点をZL17～18相当まで拡大して、自作ZL18とshi-works版ZL17を比較した。

結果：

- 山地・城郭地形について実用上ほとんど差を感じない。
- 尾根・谷・斜面など、城郭研究に必要な地形判読性は十分。
- 違いが比較的見えるのは平地・水田等の白っぽい部分。
- shi-works版は和歌山県域を連続してカバーできる点で圧倒的に有利。
- ZL17までしかないことは、本GISの用途では大きな問題にならないと判断。

## ③ 確定した仕様・方針

### A. CS立体図の位置付け

重要な基本方針として以下を確定。

> **城郭研究支援GISの運用にCS立体図は必須ではない。CS立体図がなくても公開・運用する価値はある。ただし、和歌山県全域のCS立体図を用意できれば、一段高い研究支援サービスを提供できる。**

したがって、GIS本体とCS立体図を切り離して考える。

GIS本体の主要機能は、

- 城館等の位置表示
- 城館DB検索
- DB → GIS
- GIS → DB
- 経緯度取得・ジャンプ

であり、CS立体図は重要ではあるが付加レイヤーと位置付ける。


### B. 当面shi-works版を利用して公開を目指す

比較試験の結果、shi-works版は自作ZL18と実用上ほぼ同等と判断。

したがって、

> **全県CSの自作作業はいったん保留し、当面shi-works版CSを使用してGIS公開まで進める。**

自作CS作成技術・データは廃棄せず、将来のバックアップ手段として保存する。


### C. 自作CS関連コードは現役 `main.js` から削除

Git履歴から復元可能であり、今後の保守性を優先して現役コードから削除した。

自作したDEM・CS・タイル等のデータ自体はバックアップとして残す。


### D. shi-works氏とは将来的な安定運用のため連絡を取る

正式公開前後を目安に、shi-works氏へプロジェクトを紹介し、利用方法について相談する。

単なる「使用許可をください」という依頼より、

- 城郭研究支援GISの目的
- GitHubリポジトリ
- 自分たちでも点群 → DEM → CS → XYZタイル作成を試みたこと
- shi-works版を比較した結果、研究用途に適していたこと
- 公開GISで利用したいこと
- 長期的にどのような利用方法が望ましいか

を説明して相談する方針。


### E. タイルの実体はGitHubから取得しているわけではない

現在のGISは、

```text
castle-gis
   ↓
xs489works.xsrv.jp
   ↓
必要なXYZ PNGタイル
```

という形で、閲覧のたびにshi-works氏側のタイルサーバーから画像を取得している。

**GitHubからCS画像を読んでいるわけではない。**

GitHubは公開情報・コード等の掲載場所で、CSタイル本体は別サーバーにある。


### F. タイルの自前保存について

shi-works氏の和歌山県CSについては、公開情報上 `CC BY 4.0` とされているため、適切なクレジット等の条件を守れば、複製・再利用できる可能性が高い。

ただし、

> **ライセンス上の再利用可否**

と

> **shi-works氏のサーバーへ大量アクセスして全県タイルを一括取得すること**

は別問題。

したがって、全県タイルを機械的に一括ダウンロードする前にshi-works氏へ相談する。

理想的には、

- タイル一式を提供してもらう
- 一括取得の許可を得る
- 推奨される自前ホスティング方法を教えてもらう

などを相談する。
