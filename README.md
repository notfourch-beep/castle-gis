# 城郭研究支援GIS / Castle Research Support GIS

和歌山県内の城館研究を支援するためのWeb GISです。

城館・類似地形・調査中地点などの情報を地図上に表示するとともに、独自に調査・整理した城館データを公開し、そのデータベースと地形情報を相互に参照できるシステムを目指して開発しています。

**Castle Research Support GIS** is a web-based GIS project for archaeological and historical castle research in Wakayama Prefecture, Japan.


## 目的

和歌山県内には多数の城館跡が存在しますが、近年、赤色立体地図などの活用により、山間部で未知の城が発見されるケースも増えてきました。これらの研究を進めるには、既知の城の位置情報と地形を照合しながら確認することが重要です。

本システムでは、

* 既知の城館の位置を地図上で確認する
* 城館データベースから該当地点へ移動する
* 地図上の地点から城館情報を参照する
* CS立体図などの地形情報と城館位置を重ねて確認する
* 未確認の城館候補地や類似地形の検討を支援する

ことを目的としています。


## 主な機能

現在、以下の機能を実装しています。

* 城館・類似地形・調査中地点の地図表示
* 城館データベースの検索
* 検索結果から地図上の該当地点への移動
* 地図から城館詳細情報への移動
* 地図上での経緯度取得
* 指定した経緯度への移動
* 地理院地図およびCS立体図の表示・切替

## 使用している地図・地形データ

### 地理院地図

背景地図として、国土地理院の地理院タイル（標準地図）を使用しています。


### CS立体図

地形判読を支援するため、CS立体図を重ね合わせ表示しています。

現在、和歌山県域のCS立体図として、shi-works氏が公開している和歌山県3次元点群データ由来のCS立体図XYZタイルを試験的に利用しています。

- CS立体図作成・公開：shi-works
- 原初データ：和歌山県3次元点群データ
- 解像度：1m
- ズームレベル：4–17
- ライセンス：CC BY 4.0
- 公開元：https://github.com/shiwaku/csmap-on-maplibre

本システムでは、shi-works氏が公開するXYZタイルを外部参照して表示しています。

なお、このCS立体図は提供元により試験公開中とされており、予告なく変更または公開を中止する場合があります。

本システムにおいてCS立体図は必須の構成要素ではありませんが、城館地形の確認や未知の城館候補地の検討を支援する重要な付加レイヤーとして位置付けています。


## 運用状況

本システムは、和歌山城郭調査研究会が公開・運用しています。

城館データは調査・研究の進展に応じて随時更新します。掲載している城館の位置・分類等についても、今後の調査・研究により変更される場合があります。

また、機能・データ構造・ユーザーインターフェース等についても、今後変更する場合があります。
